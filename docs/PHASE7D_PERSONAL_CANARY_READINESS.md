## Minimum trusted Memory path

1. Trusted intake establishes Personal identity and one original source. Authorized acquisition pins the actual public commit/tree/file snapshot and evidence. Research records retain objective, classification, limitations and authenticated contributors.
2. Assigned lead produces an immutable packet. Independent verifier checks each material claim and citation, source authenticity within the approved policy, contradictions, unknowns and exact packet version/digest. `REJECTED` or `NEEDS_MORE_RESEARCH` cannot progress; rework requires a new revision and bounded authorization.
3. Research sends a versioned candidate to a **Memory-owned** approved port: Personal scope, exact source/evidence, packet/version/digest, genuine execution and independent attestation references, classification/access, specialist topics, validity and relationships, stable operation identity. Candidate acceptance is not trusted storage.
4. Memory authenticates the caller and independently validates attestation authority/currentness, scope and evidence linkage. Durable commit produces a commit receipt. A separate authorized promotion operation validates the exact committed version and produces a promotion receipt. No global Alfred/bridge bearer is handed to Research to self-approve; `saved`, current create exceptions and `capture_create` are insufficient.
5. A separately authorized specialist performs a fresh retrieval through Memory, preserving full citations/provenance and enforcing current permissions and validity. A previous promotion or cached search is not a retrieval receipt. Memory must reject stale, disputed, expired, revoked, superseded or synthetic candidates.
6. Research reconciles current receipts before final preparation/send. Notify only actual success, preserving commit/promotion/retrieval and transport acceptance/delivery as separate states. Ambiguity stays incomplete; failures never trigger a fabricated receipt or blind re-execution.

Whether Memory maps these logical stages onto existing operations or adds an extension is Memory-owned. Required semantics are fixed; no new endpoint/schema is claimed to exist. Generic review's proposal digest is not a Research packet attestation.
