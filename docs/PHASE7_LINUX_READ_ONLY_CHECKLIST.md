# Phase 7 Linux read-only inspection checklist

Prepared on the Mac in Phase 7A. **Not executed on Linux.** This is not transfer, installation, adapter activation or production access authorization. Obtain separate owner authorization naming the host, allowed configuration locations and boundary owners first. Do not inspect credentials, company records, vault contents or private logs. Ask owners for redacted contracts and mappings rather than scanning the host.

For every row, record: owner; inspected contract/version and source reference; approved redacted evidence; authenticated caller and tenant mapping; request/response and receipt fields; idempotency/version preconditions; timeout/absence/reconciliation semantics; negative tests needed; unresolved questions; owner sign-off. Missing evidence leaves that adapter disabled. Historical handoff names, paths and endpoints are clues only, never current contracts.

Inspect one-source envelope/version, issued principal, conversation/environment binding, purpose/access policy, request/replay identity, cancellation/deadline and recoverable terminal-task delivery. Determine who owns dispatch and status. | Map current internal Research contracts to that hook; reject unknown or forged identity; no new global orchestrator/scheduler. |

Mac PASS is not Linux operational acceptance. |

Permitted examples **only after separate read-only authorization**: inspect `python3 --version`; run the packaged compatibility probe with `--require-linux`; inspect owner-approved unit metadata (`Id`, `LoadState`, `ActiveState`, `User`, `Group`, `WorkingDirectory`) with `systemctl show`. Do not dump environment variables, credential files, complete process arguments, logs, live database contents or vault directories. Compatibility probes do not replace filesystem/permission acceptance.

Inspection exit gate: versioned mappings and evidence for every enabled boundary, reviewed deny cases and ambiguity handling, explicit unresolved blockers, and a concrete staging/rollback proposal. Read-only discovery does not authorize transfer, installation, production probes or service changes.
